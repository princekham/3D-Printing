## Sculpting Tutorial from Udemy

- Shift+A to call menu, choose image -> reference
- Alt + R to clear the rotation
- Numpad 1 to go to the front view

```
How to Turn on Emulate NumpadOpen 
- Edit from the top menu.
- Select Preferences.Click on the Input tab on the left side.
- Check the box for Emulate Numpad.
```
- R-X-90 to rotate 90 degree along X axis
- G key for grabing and can move with mouse.
- S + ratio say 0.2 for scaling down to 0.2 %
- G + X or Y or Z to grab along an axis
- Shift+D for duplicating

  ```
  - To go to 'sculpt mode',
  - select object,
  - Ctrl + tab
  ```
  - 'Dynamic Topology' shortened as 'Dyntopo' can be turned on and off
  - after selecting a brush, Shift+ Space bar to open 'context menu'
  - 'Z' to call upon the solid, wireframe, etc. menu
  - 'F' key to change the size of the radius
  - Shift + f for the strength of the brush.

```
- with any brush, hold down 'Shift' for smoothing
- and hold down 'Ctrl' for deflating or subtracting
- shortcut for Grab is 'G'
- shortcut for Draw is 'V'
- shortcut for Crease Brush is 'Shift + C'
```

- With an object selected, a mirror modifier can be used. To use, press the wrench icon and search for mirror
- R + R to thumble rotate

#### Under Dynamic Topology
- there is 'Constant detail', 'Relative Detail'
- 'Brush Detail' is relative to the size of the brush
- 'manual detail'
- And can set the resolution


### How to View the axis

```
- Under modifier -> Viewport Display -> toggle Show Axis
```
#### In object mode, if we rotate an image, the axis will rotate with it.
#### In edit mode, when rotate, the axis will not change
#### Global and Local axis
- Global axis is Reference axis and Local axis is body axis, as I can understand.

### Creating Loop cut (it is like 'Divide' in AutoCAD, I think)
- Ctrl + R and enter no of cuts you want and then double left click for confirming
